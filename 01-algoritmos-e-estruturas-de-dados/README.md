# 01 - Algoritmos e Estruturas de Dados

Estudo de estrutura e algoritmos. O foco aqui é entender o funcionamento interno, ponteiros e alocação, com implementações limpas em C/C++.

## 📌 Sumário e Roadmap

### 1. Conceitos Fundamentais
- [x] **Recursividade:** Casos base, pilha de chamadas e Tail Recursion.
- [x] **Lineares:** Listas encadeadas (simples e duplas), Pilhas (Stacks) e Filas (Queues).

### 2. Estruturas Baseadas em Chaves e Conjuntos
- [ ] **Hashing:** Hash Tables, tratamento de colisões (Chaining e Open Addressing).
- [ ] **Set:** Implementações e propriedades de conjuntos.
- [ ] **Union-Find (Disjoint Set Union - DSU):** Compressão de caminho e união por rank/tamanho.

### 3. Árvores
- [ ] **Árvores Binárias:** Binária de Busca (BST), travessias (In-order, Pre-order, Post-order).
- [ ] **Árvores Balanceadas e LRT:** AVL, Red-Black Tree, Left-Right Tree / Left-Child Right-Sibling.
- [ ] **Árvores de Múltiplos Caminhos:** B-Trees, Tries (Árvores de prefixos).
- [ ] **Heaps:** Min-Heap, Max-Heap e Priority Queues.

### 4. Grafos
- [ ] **Representação:** Matriz de Adjacência vs. Lista de Adjacência.
- [ ] **Travessia:** Busca em Largura (BFS) e Busca em Profundidade (DFS).
- [ ] **Caminho Mínimo (Shortest Path):** 
  - Dijkstra (pesos não-negativos)
  - Bellman-Ford (pesos negativos e detecção de ciclos)
  - A* (A-Star, heurística)
- [ ] **Árvore Geradora Mínima (MST):**
  - Algoritmo de Prim
  - Algoritmo de Kruskal (usando Union-Find)
- [ ] **Componentes e Ordenação:**
  - Ordenação Topológica (para DAGs)
  - Algoritmo de Kosaraju (Componentes Fortemente Conexas - SCC)
