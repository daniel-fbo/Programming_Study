# 12 - Frameworks

Estudo dos ecossistemas, bibliotecas e frameworks que aceleram o desenvolvimento de software, abstraindo tarefas repetitivas e definindo padrões arquiteturais. O foco é entender o funcionamento interno dessas ferramentas e como elas implementam o conceito de Inversão de Controle.

## Sumário e Roadmap

### 1. Fundamentos
- [ ] Diferença conceitual entre Bibliotecas (Libraries) e Frameworks (Inversão de Controle).
- [ ] Trade-offs no uso de frameworks: Produtividade vs. Complexidade e vendor lock-in.

### 2. Frameworks Backend (Web e APIs)
- [ ] Spring Boot (Java): Injeção de dependência, Spring MVC, Spring Data.
- [ ] Node.js: Express (minimalista) vs. NestJS (arquitetura modular focada em TypeScript).
- [ ] Python: Django (baterias inclusas) vs. FastAPI (focado em performance e assincronismo).

### 3. Frameworks Frontend e SPA
- [ ] React: Virtual DOM, ciclo de vida, Hooks e gerenciamento de estado (Redux, Context API).
- [ ] Vue.js / Angular: Reatividade, two-way data binding e arquitetura de componentes.

### 4. ORMs (Object-Relational Mapping)
- [ ] Mapeamento de objetos para tabelas relacionais.
- [ ] O problema do N+1 e gerenciamento de sessões.
- [ ] Ferramentas populares: Hibernate (Java), Prisma / TypeORM (TS/JS), SQLAlchemy (Python).

### 5. Ecossistemas C / C++
- [ ] Boost: Coleção de bibliotecas portáteis (muitas frequentemente integradas ao C++ Standard).
- [ ] Qt: Framework para interfaces gráficas e aplicações multiplataforma.

## Referências Úteis
* Documentações oficiais e guias de migração de cada framework.
* Artigo: Inversion of Control Containers and the Dependency Injection pattern (Martin Fowler).
