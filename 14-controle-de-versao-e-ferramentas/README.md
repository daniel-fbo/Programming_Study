# 14 - Controle de Versão e Ferramentas

Estudo de ferramentas de versionamento de código, automação de ambiente e utilitários essenciais para o fluxo de trabalho em engenharia de software.

## Sumário e Roadmap

### 1. Git Avançado e Comandos Essenciais
- [ ] Cheatsheet de comandos fundamentais (add, commit, push, pull, fetch, status, diff).
- [ ] Manipulação e recuperação de histórico: `git rebase` (standard e interativo), `git squash`, `git cherry-pick`.
- [ ] Recuperação de alterações perdidas via `git reflog` e redefinição de estados com `git reset` (soft, mixed, hard).
- [ ] Resolução de conflitos de merge e isolamento de bugs com `git bisect`.

### 2. Fluxos de Trabalho (Git Workflows)
- [ ] Trunk-Based Development vs. Git Flow vs. Feature Branching.
- [ ] Padrões de mensagens de commit (Conventional Commits) e semantic versioning (SemVer).
- [ ] Boas práticas em Pull/Merge Requests e processos de Code Review.

### 3. Automações e Configurações de Repositório
- [ ] Configuração de Git Hooks nativos (`pre-commit`, `pre-push`) para linters e testes.
- [ ] Gerenciamento de dependências internas via Git Submodules e Subtrees.
- [ ] Modelos de `.gitignore` para diferentes projetos (C/C++, Node.js, Python) e utilitário `.gitattributes`.

### 4. Terminal e Produtividade
- [ ] Automação de tarefas repetitivas com Shell Scripting (Bash/Zsh).
- [ ] Autenticação e segurança: Gerenciamento de chaves SSH e assinatura de commits com chaves GPG.
- [ ] Uso de Makefiles para compilação, automação de builds e execução de scripts de desenvolvimento.
