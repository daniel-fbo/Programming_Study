# 00 - Programação Competitiva

Diretório dedicado ao estudo de conceitos, técnicas de resolução e templates de código em C/C++ para maratonas e juízes online. Este não é um banco de questões resolvidas, mas sim um catálogo de padrões, lógicas e trechos de código.

## Sumário e Roadmap

### 1. Fundamentos e Técnicas Base
- [ ] **Análise de Complexidade:** Cálculo rápido de Big-O para tempo e espaço.
- [ ] **I/O Otimizado:** Leitura e escrita eficientes e diretas (uso de `scanf`/`printf` e macros essenciais, evitando abstrações desnecessárias que custam tempo).
- [ ] **Two Pointers & Sliding Window:** Percorrendo arrays para somas ou subarrays contíguos.

### 2. Algoritmos Ambiciosos (Greedy)
- [ ] **Escalonamento:** Interval Scheduling, Interval Partitioning, Minimization of Lateness.
- [ ] **Problema da Mochila (Knapsack):** Versão fracionária.
- [ ] **Otimização Logística:** Gas Station Refueling Problem.
- [ ] **Sistemas de Troco:** Change-Making Algorithm.
- [ ] **Compressão de Dados:** Algoritmo de Huffman.

### 3. Dividir e Conquistar (Divide and Conquer)
- [ ] **Ordenação e Contagem:** Counting Inversions (baseado no MergeSort).
- [ ] **Geometria:** Closest Pair of Points.
- [ ] **Matemática:** Multiplicação de Inteiros (Karatsuba) e Matrizes (Strassen).
- [ ] **Seleção:** Mediana das Medianas (Quickselect para $O(N)$ no pior caso).

### 4. Programação Dinâmica (DP)
- [ ] **Intervalos e Subsequências:** Weighted Interval Scheduling, Maior Subsequência Crescente (LIS).
- [ ] **Strings e Sequências:** Alinhamento de Sequências, Longest Common Subsequence (LCS).
- [ ] **Mochila (Knapsack):** Versão 0/1.
