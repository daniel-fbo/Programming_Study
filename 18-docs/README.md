# 18 - Documentações

Centralização de especificações técnicas, projetos de sistemas, artigos, formatações estruturadas em LaTeX e relatórios técnicos em Markdown e PDF.

## Sumário e Roadmap

### 1. Documentação Técnica de Software
- [ ] Documento de Especificação de Requisitos e Regras de Negócio.
- [ ] Architecture Decision Records (ADRs): Registro de decisões técnicas e trade-offs do projeto.
- [ ] Especificações formais de APIs e Contratos de Dados.

### 2. Diagramação e Modelagem Visual
- [ ] Diagramas de Arquitetura de Sistemas e Fluxos de Dados.
- [ ] Modelagem de Banco de Dados (DER / MER).
- [ ] Diagramas de Sequência, Casos de Uso e Classes em UML.

### 3. Formatação e Automação em LaTeX
- [ ] Estruturação de documentos acadêmicos e relatórios técnicos.
- [ ] Pacotes avançados:
  - `tikz` e `pgfplots`: Criação de vetores, grafos e diagramas diretamente no código.
  - `listings` e `minted`: Formatação e highlight de código-fonte.
- [ ] Gerenciamento de referências bibliográficas com BibTeX / BibLaTeX.
- [ ] Automação de compilação via Makefiles (`pdflatex`, `xelatex`).

### 4. Gestão de Conteúdo e Assets
- [ ] Padrões de organização para armazenamento de arquivos PDF, imagens e especificações.
- [ ] Padronização de manuais de instalação, guias de contribuição e guias de estilo.

## Referências Úteis

* C4 Model for Visualizing Software Architecture (c4model.com).
* Markdown Guide (markdownguide.org).
