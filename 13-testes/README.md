# 13 - Testes

Este diretório é dedicado ao estudo da garantia de qualidade (QA), metodologias de desenvolvimento guiado por testes e estratégias para manter a confiabilidade e escalabilidade de bases de código.

## Sumário e Roadmap

### 1. Fundamentos e Metodologias
- [ ] A Pirâmide de Testes: Unitários, Integração e Ponta-a-Ponta (E2E).
- [ ] TDD (Test-Driven Development): Ciclo Red, Green, Refactor.
- [ ] BDD (Behavior-Driven Development): Especificação de comportamentos (Given-When-Then).

### 2. Testes Unitários e Mocking
- [ ] Isolamento de dependências e Test Doubles.
- [ ] Diferença entre Mocks, Stubs, Spies, Dummies e Fakes.
- [ ] Ferramentas de unidade: Google Test / GTest (C++), JUnit (Java), Jest / Vitest (JS/TS), PyTest (Python).

### 3. Testes de Integração e E2E
- [ ] Testando a comunicação entre módulos, banco de dados e APIs externas.
- [ ] Testcontainers (uso de contêineres Docker efêmeros para integração).
- [ ] Testes End-to-End simulando o fluxo do usuário (Cypress, Playwright, Selenium).

### 4. Qualidade e Cobertura
- [ ] Cobertura de Código (Code Coverage): Lines, Branches, Functions.
- [ ] Testes de Mutação: Alterando o código fonte para testar a resiliência dos testes.
- [ ] Análise estática e Linters (SonarQube, ESLint, Clang-Tidy).

### 5. Testes de Performance e Carga
- [ ] Testes de Carga (Load Testing) e Testes de Estresse (Stress Testing).
- [ ] Ferramentas de injeção de requisições: k6, Apache JMeter, Locust.

## Referências Úteis
* Livro: Test-Driven Development: By Example (Kent Beck).
* Livro: Working Effectively with Legacy Code (Michael Feathers).
* Livro: Unit Testing Principles, Practices, and Patterns (Vladimir Khorikov).
