# 02 - Paradigmas de Programação

Este diretório é focado no estudo das diferentes abordagens e modelos conceituais para a resolução de problemas em software. O objetivo é entender a teoria por trás de cada paradigma, independentemente da sintaxe da linguagem.

## Sumário e Roadmap

### 1. Programação Imperativa e Estruturada
- [ ] Controle de fluxo (sequência, seleção e iteração).
- [ ] Procedimentos, sub-rotinas e escopo de variáveis.
- [ ] Gerenciamento manual de estado.

### 2. Programação Orientada a Objetos (POO)
- [ ] Pilares: Encapsulamento, Abstração, Herança e Polimorfismo.
- [ ] Composição vs. Herança.
- [ ] Classes Abstratas e Interfaces.
- [ ] Princípios SOLID (aplicação conceitual na modelagem de domínios).

### 3. Programação Funcional
- [ ] Funções Puras e Efeitos Colaterais (Side-effects).
- [ ] Imutabilidade e persistência de estado.
- [ ] Funções de Primeira Classe (First-Class) e de Ordem Superior (Higher-Order).
- [ ] Closures, Currying e Aplicação Parcial.
- [ ] Map, Filter, Reduce e avaliação preguiçosa (Lazy Evaluation).

### 4. Programação Concorrente e Reativa
- [ ] Diferença entre Concorrência e Paralelismo.
- [ ] Controle de concorrência: Locks, Mutexes e Semáforos.
- [ ] Modelo de Atores e troca de mensagens.
- [ ] Fluxos de dados assíncronos e Observables (conceitos reativos).

### 5. Programação Lógica e Declarativa
- [ ] Foco no "o que" fazer em vez do "como" fazer.
- [ ] Fatos, regras e deduções (conceitos de Prolog).

* Livro: Structure and Interpretation of Computer Programs (SICP) - Excelente para bases funcionais.
